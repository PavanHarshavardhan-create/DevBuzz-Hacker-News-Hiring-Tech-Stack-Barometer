Project classification rules

  • Match explicit remote, distributed, WFH, on-site, and office-based phrases.
  • Assign Hybrid when hybrid is stated or both remote and on-site signals appear.
  • Use Unspecified when the posting has no clear signal.

Live classification uses the latest HN monthly hiring thread. Signals are phrase-based; the results reflect only posts with readable text at fetch time.

Methodology & limitations
How the barometer works
  1. Fetch monthly thread and top-level posting comments from the public HN Firebase API.
  2. Clean HTML, remove contact details, drop deleted / short / duplicate posts.
  3. Match 30–40 technologies using aliases and whole-word patterns.
  4. Aggregate posting share by month; dashboard reads exported JSON.
Interpret results carefully

The sample represents Hacker News employers, which may skew toward startups, English-language posts, and remote roles. A technology mention is not proof of an open role or a measure of the entire job market. Multiple technologies can appear in one posting, so posting shares can sum to more than 100%.
